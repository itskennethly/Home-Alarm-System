# Home-Alarm-System
---

A security setup designed to detect unauthorized access or emergencies within a residential property. These systems are designed to detect burglars, protect family members as well alert the authorities if there has been a break in. It provides safety for many people in the world ensuring that their stuff doesn’t get stolen.

---

📌 Project Overview This project includes two variations of code using Arduino microcontroller, Buzzer, LED, Switch, MH Sensor and OLED Display (Java Version Only). It monitors when a test dummy tries breaking into your house and warns the homeowners inside the house that there is a person breaking into the house.

Java Version: OPP design, Real Time Monitoring, OLED Display, Sensor detection
MATLAB Version: Embedded Data Visualization Monitoring System, Sensor detection

---

⚙️ Features
- Real-time home monitoring
- Automatically detects when person is entering a house
- Full on Sensor detector and OLED Interface
- Switch Activation system
- LED display for switch
